# 知错：编程实验诊断与补弱平台

独立实现的本地 Web 原型，参考 AI 引导学习的产品思路，没有复制 DeepTutor 源码。

## 启动

需要 Node.js 22 或更高版本，无第三方依赖。运行 `node --env-file-if-exists=.env server.mjs`，浏览器打开 http://127.0.0.1:3180 。Windows 可双击 start.cmd。测试：`node --test tests/*.test.mjs`。

## 已实现

- 学习成长中心 `/learning`：Python、JavaScript、Java、C、C++、TypeScript、Go 的 42 道入门阅读题、按语言隔离的最新测评记录、六维雷达图、基础知识顺序简图和基于答题证据的学习画像。
- 每个维度仅 1 题，不据此推断稳定能力、学习天赋或进步趋势。除 JavaScript 外暂不提供代码执行；知识图谱目前是可点击的教学顺序简图，非完整语言图谱。

- 四个 JavaScript 实验、普通及边界测试用例。
- Worker 中运行同步函数，1.5 秒超时后终止，支持语法和运行错误反馈。
- 三级教学提示：无密钥时明确使用预设规则，有密钥时请求模型。
- 浏览器草稿、真实测试记录、迁移练习入口、JSON 导出。
- 响应式实验工作台、知识手册、学习报告。

## AI 配置

复制 `.env.example` 为 `.env`，填写服务地址、模型名和密钥后重启。服务地址以 API 根路径为准，例如服务商提供的 `/v1` 路径需要保留。后端追加 `/chat/completions`。代码仅在主动请求 AI 提示时发送给模型服务。不要提交 `.env`。

模型接口仅绑定回环地址，校验 Host / Origin、输入体积和字段，限制每分钟 6 次调用，输出上限 650 tokens，25 秒超时。模型输出按纯文本渲染。供个人本机使用，非公网多租户服务。

## 当前边界

这是无构建依赖的原生 JavaScript 验证版；尚未迁移 React/TypeScript，因此尚未达到最终参赛前端工程目标。尚未实现上传课件、RAG、自由出题、知识掌握度算法或真实用户研究。知识依据为内置教学笔记。无提示通过次数不能证明独立掌握。

Worker 防止普通无限循环冻结界面，配合独立 CSP 阻止网络访问，但不是针对恶意代码的强安全沙箱；仅运行本人编写的练习代码，不执行来源不明代码。当前测试针对同步纯函数，不支持异步函数，也不防作弊。正式版本应采用独立源或进程级执行服务。模型生成的代码不会自动执行。
