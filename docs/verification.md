## 复现

- `npm test`、`npm run typecheck`、`npm run build`。
- `npm run check:ready`：查看密钥是否配置、Docker 和镜像是否就绪，不输出密钥。
- `node scripts/verify-runtimes.mjs`、`node scripts/verify-submissions.mjs`：基础语言执行与 HTTP 判题。
- `npm run test:browser`：常规浏览器回归。
- `npm run test:adaptive`：真实 Python AI 专项训练，临时数据目录。
- `npm run test:languages`：各语言从真实失败代码生成并验证新题；可传语言参数，只测指定语言。

浏览器测试需先安装 Chromium（`npx playwright install chromium`）。所有真实 AI 检查均使用本机模型配置，产生少量费用，使用临时数据目录，不覆盖个人学习记录。未配置密钥或未启动 Docker 时不能执行完整集成验收。

## 使用边界

发布校验是有限用例验证，不是形式化证明。AI 仍可能对错因或教学相关性作出不准确解释。自动出题仅覆盖受约束的整数数组计算。固定复测与 AI 变式记录分开；不能据此认证独立完成、长期掌握或教学因果效果。
