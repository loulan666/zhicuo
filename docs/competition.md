# 参赛范围与验收清单

依据：参赛者提供的《全国高校 AI Web 开发挑战赛》赛道要求文本，未独立核验赛事官网。文本写明作品截止 2026-11-18；实际提交时间和入口以赛事个人中心为准。

## 定位

知错：面向编程初学者的 AI 实验诊断与补弱平台。针对“看懂讲解却不会独立写程序”的问题，将阅读测评、真实代码测试、只读工具调用、课程资料检索和复测验证连接起来。重点演示真实证据驱动的教学，而非通用聊天窗口。

## 评分对照

| 评分项 | 本项目实现与证据 | 边界 |
| --- | --- | --- |
| AI 技术深度 35% | DeepSeek；受限 Function Calling；证据读取、补练计划与资料检索；诊断调用轨迹；超时与限流 | 非多模态；非 MCP；检索为关键词，不是向量数据库 |
| 创新性 25% | 原实验失败→排查方向→补练→独立复测；报告与真实判题分离 | 相同任务换输入，不是完整自适应题库 |
| 前端工程 10% | React、TypeScript、独立 Coach 组件、构建、类型检查 | 其余页面仍可进一步拆分 |
| 实用性 10% | 七种语言、本机执行、资料导入、数据导出 | 当前单人本地使用 |
| 用户体验 10% | 状态反馈、取消诊断、来源片段、雷达和知识依赖图 | 无流式逐字输出；展示实际工具轨迹而非模型思维链 |
| 社会价值 10% | 用测评和实验支持初学者定位薄弱点，不推断学习天赋 | 没有真实班级学习效果研究，不虚构提升比例 |

## 可复现验证

1. npm ci；npm run typecheck；npm test；npm run build。
2. 启动 Docker，执行 scripts/setup-runtimes.ps1。
3. node scripts/verify-runtimes.mjs：七种语言正常与空输入。
4. node scripts/verify-submissions.mjs：HTTP 判题和数据存储。
5. 配置 .env 并启动 npm start，在 AI 诊断工作台生成报告，核对实际工具调用与证据。
6. 检查评审电脑上能运行全部流程；无网络时容器可运行，DeepSeek 无法提供在线诊断，界面应明确报错。
